# Tuesday Night Arguing

One Dungeons & Dragons campaign told twice by the same person: **Noct**, a dwarf bard
with a generous memory, and the man playing him on a Tuesday night over Discord. The
first person flips between them, and so does the design.

```bash
npm install
npm run dev      # http://localhost:4321
```

## The three apps

| App | Repo | What it is |
|---|---|---|
| **Tuesday Night Arguing** | this one | The adult group's novel, public |
| **Ruins of Ethium** | [`RuinsOfEthium`](https://github.com/Twoshedzz/RuinsOfEthium) | The same campaign for the kids' table, public |
| **Ethium Source** | `EthiumSource` (private) | World canon, modules, maps, and both tables' records |

**Nothing in this repo is secret and nothing in it is canon.** Noct's notebook, the beat
sheet, the world and the prep all live in EthiumSource. This repo holds the book.

## Writing a chapter

Everything is authored under `publish/`. `src/content/chapters/` and
`public/illustrations/` are generated by `scripts/sync-publish.mjs` on every `dev` and
`build`, and edits there are overwritten.

```bash
cp publish/chapters/_template.md publish/chapters/02-your-slug.md
```

The numeric prefix orders the files; the filename becomes the URL. Frontmatter takes
`title`, `chapter`, `summary`, `coverIllustration` and `published`.

The two registers are marked with two wrappers inside the markdown —
`<aside class="room">` for an interruption and `<aside class="read-aloud">` for
something heard. [`publish/source/style-guide.md`](publish/source/style-guide.md) has the
markup and the voice rules.

| Command | Does |
|---|---|
| `npm run dev` | Sync + dev server |
| `npm run build` | Sync + production build (**the verification step**) |
| `npm run publish` | Sync only |
| `npm run deploy` | One deliberate Netlify build |

**Append `[skip netlify]` to every commit message.** Build credits cost money. Deploy
only when you mean to.

## Shared with the other book

This app shares its layout and components with Ruins of Ethium — same chapter reader,
same navigation, different skin. A fix to the reader in one repo is worth applying to
the other; there is no shared package, so it has to be done by hand, and that is
deliberate.
